# 11단계 피드백 — 출퇴근·급여 (3-1 ~ 3-3)

> ⚠️ **갱신(권한 정리 후):** 이 문서에 나오는 개발용 임시 정책·고정 사용자(`devUser.js`)·"로그인하면 함수 권한 없음"은 `20261028000100_auth_permissions.sql`로 모두 해결됐다. 현재 상태와 남은 것은 [develop_통합_이슈.md](develop_통합_이슈.md) 참고.

## 한 일
- 3-1 출근·퇴근: `clock_in` / `clock_out` 함수. 출근은 오늘(한국 시간)의 **확정** 근무 배정 중 아직 출근하지 않은 첫 근무에 자동 연결, 배정이 없으면 예정 없이 기록. 퇴근 전 재출근·출근 없는 퇴근은 거부
- 3-E1·E2 (BEFORE 트리거): 실 근무시간(소수 둘째 자리)과 지각·조퇴·지각·조퇴·정상 판정을 자동 기록 (분 단위, 예정보다 늦은 출근 / 이른 퇴근)
- 3-2 급여: `recalc_payroll` — 주(월~일) 단위, 기본급 = 근무시간 × 시급, 주 15시간 이상이면 주휴수당(기본급 ÷ 5), UPSERT. 퇴근이 기록되면 그 주 급여 자동 갱신 + 본인에게 알림(3-E3)
- `calculate_payroll`: 지난주(또는 지정 주) 급여 일괄 계산. 15단계 스케줄러가 부름
- 3-3 인건비 비교: 이번 달 직원별 **예정**(확정 근무 배정 시간 × 시급) vs **실제**(출퇴근 기록 시간 × 시급), 이번 주 출퇴근 기록과 지각·조퇴 표시를 DB에서 읽음
- 화면: 알바생 출퇴근(예정·기록 표시, 출근/퇴근 버튼) / 알바생 급여(이번 달 근무 내역·예상 급여·주휴수당) / 점주 출퇴근·인건비
- 시드 급여가 그대로 재현됨: 정윤수 186,379원, 장윤서 61,920원 (시드의 주휴수당 계산식과 같음)

## 내가 해야 하는 것 ✋
1. **원격 DB에 마이그레이션 적용** (14단계까지 적용한 뒤)
   - `supabase/migrations/20261024000100_attendance_payroll.sql`
   - `supabase/migrations/20261024000200_dev_policies_attendance_temp.sql`
2. `supabase/tests/attendance_payroll.sql`을 SQL Editor에서 실행해 확인
3. 화면 확인: 알바생 > 출퇴근 (예정이 "없음"으로 보이는 게 정상 — 오늘 날짜의 확정 근무가 시드에 없음), 점주 > 출퇴근·인건비, 알바생 > 급여
4. **오늘 날짜의 확정 근무가 있어야 예정 연결·지각 판정을 화면에서 볼 수 있다.** 5~7단계(스케줄 확정) 담당자의 작업이 끝나거나, 테스트용으로 오늘 날짜 `shift_assignment`(확정된 `work_schedule` 연결)를 직접 넣어야 함
5. 출퇴근 버튼은 원격 DB에 실제 출퇴근 기록을 만든다. 데모 데이터를 깨끗이 유지하려면 누르고 나서 `attendance` 행을 지우거나 팀과 먼저 확인

## 막힌 부분 🚧
- 스케줄 확정(2-5)이 아직 앱에 없어서 **예정 근무가 있는 실제 출퇴근 흐름은 DB 테스트(SQL)로만 검증**함. 화면에서는 "예정 없음" 상태의 출퇴근만 확인 가능
- 시드의 `work_schedule`에는 오늘 주(10.19)의 '초안'만 있고 '확정'은 10.05 주뿐이라, 이번 달 예정 시간(3-3)은 10.05 주 근무만 잡힘
- 급여는 **주 단위**(테이블이 `(user_id, period_start)` 유일): 화면의 월 예상 급여는 이번 달 출퇴근 시간 합 × 시급 + 주휴수당 합으로 계산 (월 단위 확정 급여 테이블은 22개 확정 규칙 때문에 만들지 않음)
- 시급 정보를 화면에서 읽도록 `user_account.hourly_wage` 컬럼을 anon에 열었음(개발용). **인증 후에는 본인·점주만 읽도록 제한 필요**
- 출퇴근 수정(매니저가 잘못된 기록 고치기)은 프로세스 목록에 없어서 구현하지 않음. 퇴근을 누르지 않으면 다음 출근이 막힘 → 직접 DB에서 수정해야 함
- 야간 근무(자정 넘김)는 지원하지 않음 (카페 영업시간 8~22시 기준)
- 프런트 쿼리(조인·필터)는 빌드로만 확인했고 원격에는 정책이 없어 읽기를 못 돌려봄 → 적용 후 알려주면 읽기 검증 스크립트를 돌려 확인

## 확인 결과
- 로컬 PostgreSQL 검증: 시드 급여 재현, 정시/지각/지각·조퇴 판정, 근무시간 4.88·4.17, 주 19.05시간에 주휴수당 39,319원, 퇴근마다 급여 갱신 알림 4건, 재출근·출근 없는 퇴근 거부, 예정 없는 출근 '정상' 모두 통과
