# 프로젝트 배경 (카페·식당 매출예측·근무표 자동화 솔루션, 5조)

> 이 문서는 `CLAUDE.md`에서 분리한 내용이다. 설계 산출물 원본은 `산출물/` 폴더에 있다.

## 프로젝트 개요
- 과제명: 카페·식당 매출예측·근무표 자동화 솔루션
- 학과/학급: 컴퓨터소프트웨어과 3A / 지도교수: 김규억 / 참여업체: 나모웹비즈 주식회사 / 팀: 5조
- 팀원: 김태현(학생대표), 김찬영, 정윤수, 장윤서, 김기연, 이채림
- 성과물: **소프트웨어 개발** — 매출 데이터를 분석해 피크타임을 파악하고 근무 스케줄과 재료 발주량을 자동 산출하는 웹 기반 서비스(프로토타입)
- 목표: "감이 아니라 데이터로 발주하고 근무표 짜는 카페". 예측과 실제의 오차를 매주 보정해 낭비를 줄인다.
- 제작 계획: ① 매출 패턴 분석 + 근무 가능시간 등록 → ② 스케줄 자동 생성 + 출퇴근·급여 → ③ 재고·권장 발주량 → ④ 예측 오차 보정. 초기에는 핵심 메뉴 몇 개로 범위를 좁혀 시작한다.
- 기대효과: 점주는 재료 폐기·인건비 낭비 감소, 알바생은 가능 시간이 반영된 근무표와 정확한 급여, 손님은 품절 감소

### 의뢰 배경 (원문: [사용자 요구사항 5조.pdf](<../산출물/사용자 요구사항 5조.pdf>))
- 고객: 카페 "카페 온기" 점주 윤소라 (3년째 운영)
- 문제: 발주와 인력 배치를 감으로 결정해 폐기 재료가 나오고, 피크에는 인력이 부족하고 한산할 때는 남는다. 요일·시간대별 매출 패턴이 정리되지 않았고 예측 오차를 사후 조정할 체계가 없다.
- 제약: 예산은 소규모 카페 수준(금액 미정), 데이터 분석 기법 활용 수준이며 자체 대규모 모델 개발은 아님, 별도 마감 없음. 재고는 처음엔 대충 입력해도 되니 일단 돌아가는 것을 보고 싶다는 요청.
- 설계 단계의 역할은 점주·매니저·알바생 3종이다(원문의 손님은 간접 이용자).
